# Quotes Scraper

**What it does**: A Python script that visits https://quotes.toscrape.com/, collects the Text,Author and Tags of each Quotes on all 10 pages, and saves them to quotes.csv.

**How to run it**:
 1. pip install selenium
 2. You should also have Chrome instaled in your computer 
 3. Run the script:
                   python quotes.py

**Output:** `quotes.csv` with 100 quotes (columns: Text, Author, Tags)

**Tools used**:
Python, Selenium
